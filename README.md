# Recommendation-System
This project is a simple AI-based Movie Recommendation System developed using Python and Machine Learning techniques.  The system recommends movies based on similarity between movie genres using Cosine Similarity and Count Vectorization.
## Features
- Recommends similar movies
- Uses Machine Learning algorithms
- Simple and beginner-friendly
- Fast recommendation system
- Runs in Google Colab and VS Code
- Content-based filtering approach
## Technologies Used
- Python
- Pandas
- Scikit-learn
- CountVectorizer
- Cosine Similarity
- Google Colab
##  How It Works
1. Movie dataset is loaded
2. Movie genres are converted into numerical vectors
3. Cosine similarity is calculated
4. Similar movies are identified
5. Recommended movies are displayed
